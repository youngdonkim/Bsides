# 와이어프레임 — 사람 review 전용

사용자가 sketch 단계에서 화면 layout을 빠르게 직관 파악하는 보조 자료. **Claude Design 핸드오프엔 미포함** — Claude Design에는 시나리오·플로우·매핑 표만 input으로 전달해서 brand guide 정합으로 free layout 탐색 가능하게 함.

데스크톱 기준. 모바일은 동일 컴포넌트를 세로 stack(반응형).
