출시(13)에서 N=1~5 직접 검증을 통과했으면, **채널 1~2개 실험**으로 N=10s~수백으로 확장. **광고 X, 본격 캠페인 X** — MVP는 학습 단계라 비용 vs 결과 불확실. **만든 사람의 1인칭 이야기**가 핵심.

## 1. 단계 목표

- **채널 선정** — 타겟이 실제로 있는 곳 1~2개
- **첫 게시물 작성·게시** — 1인칭 이야기 + 핵심 동작 1장 + URL
- **반응 24~72h 측정** — 클릭·체류·전환·자연어 피드백
- **반응 해석** — 가설 검증, 채널 적합도, 다음 사이클 input

## 2. 진행 절차

### 2.1 사이클 분기

- 첫 MVP 마케팅(`v2-mvp`): 채널 1개부터. 작게.
- 이후 사이클: 이전 반응 base로 채널 변경 또는 게시물 톤 조정.

### 2.2 자동 점검 (AI 단독)

- 출시(13) `launch-checklist.md` 통과 신호 확인 (N=3+ 좋은 지표 반복)
- 분석 작동 (signup/key action funnel 측정 가능)
- 브랜드 essence·voice (`brand-guide.md`) 확인 — 게시물 톤 base

### 2.3 사용자 결정 — 채널 선정

```
마케팅 채널 선정 — 1~2개. 후보 카테고리:

- 메이커 커뮤니티 (Disquiet · GeekNews · ProductHunt)
- SNS (X/트위터 · 인스타 · 스레드)
- 뉴스레터 (자기 뉴스레터 또는 게스트)
- 콘텐츠 (블로그 · 미디엄 · 브런치)
- 커뮤니티 (관련 슬랙·디스코드 그룹)
- 오프라인 (밋업 · 코워킹 sharing)

타겟이 실제 있는 곳·운영자가 부담 안 가는 곳 우선.
```

기준:
- **타겟 사용자가 실제로 있나?** (없으면 노출 0)
- **솔로 메이커 인내 비용** (관리 시간 vs 결과)
- **제품 핵심과 정합** (B2C SaaS는 X·디스코드, 콘텐츠 제품은 뉴스레터·블로그 등)

### 2.4 게시물 작성

**구조** (한 게시물 = 한 메시지):

```
[1] 후크 — 한 줄. 사용자가 멈출 만한 문장.
[2] 출처 스토리 — 2~3 문장. 왜 만들었나 (intent.md 흡수).
[3] 핵심 동작 1개 — 스크린샷·GIF 1장 + 한 줄 설명.
[4] 어디서 써볼 수 있나 — 링크 1개.
```

**원칙**:
- 1인칭 (만든 사람의 동기)
- brand-guide.md essence·voice 그대로
- **광고 카피 금지** ("혁신적인 N배 빠른 X" 류)
- 한 게시물 한 메시지 — 여러 기능 넣지 말기

`channel-experiments.md`에 게시물 초안 저장 → 운영자 검토 후 게시.

### 2.5 반응 측정 (24~72h)

**정량**:
- 클릭 수 (UTM·referrer)
- 체류·완주율
- signup 또는 key action conversion

**정성**:
- 댓글·DM·이메일 피드백
- 추천 의사
- "친구한테도 보여줘도 돼?" 시그널

`channel-experiments.md`에 결과 기록:

```markdown
## 채널 1: {이름}
- 게시 일시: YYYY-MM-DD HH:MM
- 게시물 link: ...

### 24h 결과
- 클릭: N
- signup: M
- 자연어 피드백: ...

### 72h 결과
- 클릭 누적: ...
- ...

### 해석
- 채널 적합도: {높음·중간·낮음}
- 게시물 톤 적합도: ...
- 가설 검증: {H4 PMF 시그널 등}
- 다음 액션: {채널 1 더 / 다른 채널 / 게시물 톤 조정 / 사이클 종료}
```

### 2.6 가설 검증·종합

- 채널·게시물 N개 실험 결과 종합
- PMF 시그널 강·약 판정
- 다음 사이클 입력 도출:
  - PMF 시그널 강 → production 진입 검토
  - 약 → MVP revision (가설·기능 조정 후 다음 MVP 사이클)
  - 채널 부적합 → 채널만 바꿔 재실험

## 3. 완료 체크리스트

- [ ] 채널 최소 1개 선정·게시
- [ ] 게시물 brand-guide.md essence 정합 확인
- [ ] 반응 측정 (정량·정성) 24~72h
- [ ] `channel-experiments.md` 기록 완료
- [ ] PMF 시그널 판정 (강·중·약)
- [ ] 다음 사이클 입력 결정 (production 진입 / MVP revision / 채널 재실험)

## 4. 산출물 스펙

위치:
- `planning/cycles/v{N}-mvp/marketing-plan.md` (채널 전략·게시물 톤 plan)
- `planning/cycles/v{N}-mvp/channel-experiments.md` (실험·결과 기록)

## 5. 사이클 업데이트 모드

다음 MVP 사이클(`v3-mvp-revision`):
- 이전 사이클 `channel-experiments.md` 발견을 base로 새 plan
- 채널 종합 평가 (어디가 적합/부적합) → revision focus

## 6. 좋은 예 vs 나쁜 예

- **채널 선택** — 좋은: "Disquiet 1개부터. 타겟 메이커 다수 활동." / 나쁜: "5개 채널 동시 (관리 폭주)".
- **게시물 톤** — 좋은: "출근길에 [내 문제]를 풀려고 만들었어요. 이게 어떻게 작동하냐면..." / 나쁜: "🚀 혁신적인 AI 서비스 X 출시! 지금 무료로 만나보세요".
- **결과 해석** — 좋은: "Disquiet에서 클릭 8/conversion 0. 채널은 맞는데 카피가 약함. 다음 사이클 카피 톤 조정." / 나쁜: "마케팅이 잘 안 됐어".
- **다음 사이클 결정** — 좋은: "PMF 시그널 약함 → v3-mvp-revision에서 가설 1 변경 후 재실험". / 나쁜: "production 진입" (검증 부족).

## 7. 사용자 응대 톤 + 인터뷰 코칭

- **톤**: SKILL.md §1.3대로 반말·친근·짧게.
- **코칭**: SKILL.md §1.4대로. 채널 모호하면 후보 표 제시. 게시물 초안 받으면 brand-guide essence·voice 위배 여부 점검 후 spot 수정 제안. 결과 해석 모호하면 정량(클릭·conversion)과 정성(피드백 톤) 둘 다 base로 판정 유도.
